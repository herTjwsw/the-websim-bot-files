3. HOW TO PROMPT ME WELL (tips & tricks)
--------------------------------------------------------
TIP 1: PING ME.
  I stay quiet unless a message is clearly for me. Ping
  <@1368449539496742934> or reply to one of my messages
  and I'll always answer.

TIP 2: BE SPECIFIC ABOUT THE DELIVERABLE.
  Weak:  "make something cool about space"
  Strong: "make a 2d game where you dodge asteroids,
           retro pixel style, with a score counter"
  The more concrete, the better the first try.

TIP 3: ATTACH REFERENCES.
  Send screenshots, sprite sheets, images, code files,
  datasets. I can pull attachments from your message and
  build directly from them. "recreate this UI" + image
  works great.

TIP 4: ITERATE, DON'T RESTART.
  After I deliver a project, just say "now add X" or
  "make the button blue". I edit the SAME project and
  push updates - the URL stays the same.

TIP 5: ASK FOR MULTIPLE THINGS IN PARALLEL.
  "make 3 different games" -> I spawn subagents and they
  all build at once, each pinging you when done.

TIP 6: USE THE RIGHT VERB.
  "make/build/create a website" -> WebSim project
  "draw/generate an image"       -> image gen
  "make a video of"              -> video gen
  "run this script"              -> sandbox terminal
  "make a gif"                   -> frame animation
  "find an image of"             -> web image search

TIP 7: PERSONALITY MODES.
  You can ask me to adopt a style ("talk like a pirate",
  "uwu mode", "be formal") and I save it permanently for
  YOU only. Say "clear my mode" to remove it. Modes can
  have activation words if you want.

TIP 8: MEMORY.
  Tell me facts about yourself - name, interests,
  preferences - and I store them. "remember that I like
  X" also works. I never announce saving, I just do it.

TIP 9: REMINDERS & TASKS.
  "remind me in 30 minutes to check the oven" works.
  I can also track multi-step build tasks.

TIP 10: DON'T ASK ME TO DO OTHER PEOPLE'S BIDDING.
  I only timeout/strike people I personally see breaking
  rules. I only change the nickname of whoever asks.
  I only run admin commands for Trey (verified by user
  ID, not display name - nobody can fake that).
